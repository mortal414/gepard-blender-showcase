# R39 Base and Equipped — gallery provenance

The 16 supplied model-only JPEGs and the supplied model-only comparison board come from the verified R39 handoff. JPEG comments/EXIF/XMP are removed without recompressing the images; decoded pixels are verified identical to the supplied originals. No model is opened, changed, resaved or rerendered for this gallery update. Reference photographs, private photo comparisons, marked workbooks and local file paths are excluded.

Each native Blender file includes Camo and Charcoal, with `REFINEMENT_Camo` as its opening scene. The provided native receipts record independent reopen PASS in Blender 4.5.16 LTS and 247 packed images per model. Each image sidecar pins the variant source SHA-256, finish, camera, saved equipment state and original JPEG SHA-256. The public manifest selects these fields without including local source paths or private research records.

The supplied native renders use Cycles, standard denoising, 48 samples and the same three-area-light studio setup for matched views. AgX, Medium High Contrast, +0.6 exposure. Matched rear-quarter views are 1440 × 810; other views are 1440 × 960. The roof close-up uses its dedicated camera to make the beacon or capped socket visible. No generative imagery, reference-photo compositing or manual image retouching is used.

Base is the default presentation, led by `Base_Camo_rear_right_match.jpg`. Equipped has its own model link and gallery, led by `Equipped_Camo_front_left.jpg`, then `Equipped_Camo_roof_left.jpg`. The rear-quarter comparison shows the upright or folded dish, the turret rear wall and the empty or occupied stern deck.

The Base lower rear-wall access-panel dimensions are approximate. The Equipped combination of the full amber lamp with the roof boxes is an artistic reconstruction; the socket placement follows the supplied capped-post photographs. Those reference images remain local.
