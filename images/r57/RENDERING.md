# R57 whole-model rendering provenance

The fresh studio set contains 22 native Blender renders: eleven for Base and eleven for Equipped. Each configuration has five Camo exterior/access views, three Camo interior views, two Charcoal exterior views and one neutral clay view. The main presentation covers the model generally. The supplied change board and two original portraits are retained on the secondary revision-detail page.

Rendered in Blender 4.5.16 LTS with Cycles, NVIDIA OptiX, 96 samples, adaptive sampling, OpenImageDenoise, a 2048-pixel texture limit and a fixed studio setup. Output is 1600 × 1100. Exterior cameras match between configurations; an interior viewpoint is adjusted for Equipped where fitted roof stowage blocks the hatch sightline. The camera, studio lights and floor are presentation objects. Source geometry, UVs, material assignments and authored local poses were compared before and after rendering. Hatches and seats are temporarily posed for access, then restored. Both source copies and original master hashes remain unchanged; no Blender file is resaved.

The public JPEG copies remove EXIF/comments and private project metadata without reencoding. Decoded pixels are checked identical to each native render or supplied JPG. No generative image editing, compositing with reference photographs or manual pixel retouching is used. The source hashes and camera/pose records are in the image manifest. Reference photos, workbook and private comparison boards remain local.

R57 Base and Equipped have both been downloaded from their private Drive source folders, reassembled with the supplied helper and verified against the owner's exact hashes. R56 Base and Equipped are likewise preserved and restore-verified. The ordinary Git payload contains only model renders, text and verification records; no native Blender file, source ZIP or transport parts are included. Earlier galleries and RIGHTS.md attribution remain unchanged.
