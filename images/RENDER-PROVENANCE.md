# Gepard Blender studio gallery

Six actual Blender Cycles renders of the same saved model, with matching views for camouflage and charcoal finishes:

- Front three-quarter
- Rear three-quarter
- Turret and grey-mechanism close-up

The model geometry, materials, markings, textures and assembly are unchanged. Cameras, studio lighting, color management and a matte presentation floor were set only for these renders. These are Blender presentation images, not Arma Reforger screenshots and not photographs of a real vehicle. No generative imagery, paint-over, geometry repair or post-render retouching was used.

Each image has a JSON sidecar with the exact camera, resolution, render settings and image checksum. Full-resolution PNG originals are retained.
